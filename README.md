# stringFormatter
String Formatter adalah  Utility JavaScript sederhana untuk memformat string dan menghapus spasi berlebih di awal dan akhir string

# Fitur  
* Trim Leading &amp; Trailing Whitespace : Menghilangkan spasi, tab, dan line-break di awal serta akhir string.
